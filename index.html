The Toolkit

Your Raw Materials

The Mandate: No Frameworks. Master the fundamentals first. Built exclusively with core HTML5, CSS3, and Vanilla JavaScript.

HTML5 Infrastructure & Semantic Landmarks

Not just div tags, but structural HTML5 tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`) that provide exact meaning to browser engines and screen readers.

<header class="site-header" role="banner"> <nav aria-label="Primary navigation">...</nav> </header> <main id="main-content" role="main"> <section aria-labelledby="section-title">...</section> </main>

CSS3 Skin: Grid, Flexbox, & Container Queries

Pure CSS styling with custom CSS variables for light/dark themes, CSS Grid macro layouts, Flexbox components, and responsive clamp math.

:root { --color-mocha: #A5866F; --color-ethereal: #A0D4E0; --font-size-2xl: clamp(1.875rem, 1.5rem + 1.875vw, 3rem); } .features-grid { display: grid; grid-template-columns: repeat(auto-fit, minmax(260px, 1fr)); gap: var(--spacing-4); }

JavaScript Logic: Native DOM & State Management

Zero dependency logic handling theme persistence via localStorage, form input validation with ARIA live region error alerts, and throttled scroll listeners.

const ThemeToggle = (() => { function toggle() { const current = document.documentElement.getAttribute('data-theme'); const next = current === 'dark' ? 'light' : 'dark'; document.documentElement.setAttribute('data-theme', next); localStorage.setItem('theme', next); } return { toggle }; })();

FAQ

Frequently Asked Questions

Everything you need to know about the architecture and methodology behind Project 1.

Why build without CSS or JS frameworks?

As specified by the Project 1 Mandate: "No Frameworks. Master the fundamentals first." Building with pure HTML5, CSS3, and Vanilla JavaScript ensures lightweight code, instant load times, and mastery of browser standards.

What is "The Golden Rule" in Slide 2?

The Golden Rule states: "If it doesn't work in grayscale, color won't fix it." You can test this live on this site by clicking the Grayscale button in the header bar!

What font pairings are used in 2025 Aesthetics?

Slide 4 mandates a maximum of 2 font families. We pair Montserrat / Inter for bold geometric headlines and Roboto / Open Sans for crisp body typography.
