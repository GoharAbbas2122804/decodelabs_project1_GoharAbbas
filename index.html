FAQ

Frequently Asked Questions

Answers to common questions about this project and its implementation.

What technologies are used in this project?

HTML5, CSS3, and Vanilla JavaScript only. No frameworks, no libraries, no dependencies. Pure frontend fundamentals.

How is the responsive layout achieved?

Using CSS Grid for macro page layouts and Flexbox for micro components. Media queries use min-width for a mobile-first approach with breakpoints at 320px, 480px, 768px, 1024px, 1280px, and 1440px.

Is this project accessible?

Yes. The project follows WCAG 2.1 AA guidelines with semantic HTML, proper ARIA attributes, keyboard navigation, visible focus states, and sufficient color contrast ratios.

Does it support dark mode?

Yes. A theme toggle switches between light and dark modes using CSS custom properties. The preference is saved to localStorage and respects the system's prefers-color-scheme setting.

How is form validation handled?

Client-side validation with real-time feedback on blur. Error messages appear with proper ARIA role="alert" attributes. The form validates name, email, subject, and message fields before submission.
